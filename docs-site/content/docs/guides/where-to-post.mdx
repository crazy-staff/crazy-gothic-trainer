**Everything is in English** — ideas, comments and questions — so everyone can follow and help.

| You have… | Where |
|---|---|
| A new feature idea | [Feedback](/) — one idea per post. Search first and vote if it already exists. |
| A question | [Support](/support), or search these docs first. |
| A bug or a crash | The in-game **Tester hub** (best — it attaches everything) or [GitHub Issues](https://github.com/dawidseipold/gothic1-crazy-trainer/issues/new/choose). |

## What happens with an idea

<Steps>
<Step>

**Pending** — new ideas wait for review. Votes help decide.

</Step>
<Step>

**Approved / Planned** — the idea appears on the [Roadmap](/roadmap) and gets a GitHub issue for the work.

</Step>
<Step>

**In progress → Needs verification** — it is in a test build and testers confirm it works.

</Step>
<Step>

**Done** — shipped and listed in the [Changelog](/changelog). Voters get notified at every step. Ideas that will not be done are marked **Rejected** with a reason.

</Step>
</Steps>

Ports of open-source Union plugins and mods are welcome **with credit** — link the source in your idea.
