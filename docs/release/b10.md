## Installation
1. Download **G1CrazyTrainer_build10.zip** (below, in *Assets*) and unpack it.
2. Copy all files into `Gothic\system\Autorun` (replace the old ones).
3. Start the game with **Union + GD3D11**, load a save, press **Insert**.

> The in-game menu is in Polish for now — English is planned.

## What's new in build 10
Changes from the [Build 10 milestone](https://github.com/dawidseipold/gothic1-crazy-trainer/milestone/2).

- **Portraits (#3):** one character at a time, clone without routine, studio above the hero (background = sky), waiting until the previous clone is gone, crash assigned to the character and skipped.
- **Characters taken out of the world by the game** (empty "skeletons"): spawner, arena, "Guard the party", summon and "Wait" put them back (#17, #33, #35).
- **Item spawner:** scrolling is back, nothing is cut off (#29).
- **Tester hub:** editing your own reports (#27), text fields with wrapping and resizable height (#28), no sending to GitHub from the game — only reports (#30).
- **ESP:** separate switches for characters and items (#15). **No-clip:** the camera follows mouse rotation, "Run" mode removed (#20). **Marvin:** the switch shows the game's state (#23). **Arena** in Fun › Combat (#34).
