## Installation
1. Download **G1CrazyTrainer_build12.zip** (below, in *Assets*) and unpack it.
2. Copy all files into `Gothic\system\Autorun` (replace the old ones).
3. Start the game with **Union + GD3D11**, load a save, press **Insert**.

> The in-game menu is in Polish for now — English is planned.

## Build 12
- **Spawner:** switch "When the character is already in the game: Move the original / Create a copy"; characters from the `insert` command go to the spawned list.
- **Party:** after a conversation the companion keeps following (party flag every second); "Wait" just stands (routine off until "Return to post"); changing the hour does not take away the party or spawned characters.
- **World speed:** option "Party at normal speed".
- **No-clip:** no damage; glide without physics — the character stands and does not fall; camera switch removed.
- **Character:** Stats + Skills → Information; look in one card.
- **New info window** (Tools › Overlay): FPS, coordinates, speed, time, world, HP/mana, target — each can be turned on separately.

> Test version — back up your game saves.

## Build 12
- **Spawner:** przełącznik „Gdy postać już jest w grze: Przenieś oryginał / Utwórz kopię”; postacie z komendy `insert` trafiają na listę zrespionych.
- **Drużyna:** po rozmowie towarzysz wraca do podążania (flaga drużyny co sekundę); „Czekaj” po prostu stoi (rutyna wyłączona do „Wróć na posterunek”); zmiana godziny nie zabiera drużyny ani zrespionych.
- **Tempo świata:** opcja „Drużyna w normalnym tempie”.
- **No-clip:** bez obrażeń; ślizg bez fizyki — postać stoi, nie spada; usunięty przełącznik kamery.
- **Postać:** Statystyki + Umiejętności → Informacje; wygląd w jednej karcie.
- **Nowe okno informacji** (Narzędzia › Nakładka): FPS, koordynaty, prędkość, czas, świat, HP/mana, cel — każde do włączenia osobno.
