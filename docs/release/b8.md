## Installation
1. Download **G1CrazyTrainer_build8.zip** (below, in *Assets*) and unpack it.
2. Copy all files into `Gothic\system\Autorun` (create the folder if it does not exist).
3. Start the game with **Union + GD3D11**, load a save, press **Insert**.

> The in-game menu is in Polish for now — English is planned.

Requirements and details: [README](https://github.com/dawidseipold/gothic1-crazy-trainer#installation). Updating = replacing the files, settings are kept.

## What's new in build 8 — Tester hub
- Separate window with tabs: **Checklist**, **Reports**, **+ New report**, **Send**, **Log**.
- Next to every option (in tester mode) a **flag** opens a report form for that option.
- Nothing is overwritten: every rating and report goes to the history, and each option shows everything already known about it (author's notes, known problems from GitHub, earlier reports).
- Automatic log: what you turned on/ran and what errors the trainer caught — attached to reports.
- After a crash the trainer prepares a draft report by itself.
- Sending: a prefilled GitHub form in one click, a report file with everything, or text for Discord.

How to test: **[TESTING.md](https://github.com/dawidseipold/gothic1-crazy-trainer/blob/main/TESTING.md)**

## Also includes the build 7 fixes
No lag when changing settings, the menu no longer passes keys to the game, "Set" buttons next to stats, new portraits (4 shots), look preview on a double, arena with knockdown and rewards, spell rain limits, faster ESP, tests in a separate window, "x" in text fields.
