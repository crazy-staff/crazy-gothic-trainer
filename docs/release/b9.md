## Installation
1. Download **G1CrazyTrainer_build9.zip** (below, in *Assets*) and unpack it.
2. Copy all files into `Gothic\system\Autorun` (replace the old ones).
3. Start the game with **Union + GD3D11**, load a save, press **Insert**.

> The in-game menu is in Polish for now — English is planned.

## What's new in build 9
Everything from the [Build 9 milestone](https://github.com/dawidseipold/gothic1-crazy-trainer/milestone/1) — every change has its own issue.

**Tester hub**
- No more red ImGui error popup (#5).
- Filter by the author's dot (#6), reports for categories / subcategories / cards / aspects (#7, #8).
- Attachments: screenshot with Ctrl+V and files from disk; report with attachments as .zip (#9).

**Mods**
- Portraits: each character in its own spot + waiting a few frames, option to make portraits of all characters in the game (#3); **Compendium** in Tools (#4).
- Spawner: humans appear with their model (#17), list of spawned characters with removal (#18), spawn any instance by name (#19).
- Party: "Wait" keeps the character in place (#16).
- Visuals: subcategories, master ESP switch, separate item range (#15).
- No-clip: the mouse turns the character, camera always behind, new "Run" mode, landing on grates (#20, #21).
- Return to the Nameless Hero when the game removed him (#22). Marvin mode turned on in the game is no longer turned off (#23).

**Interface**
- Teleport: place type icons and chips (#10), even paddings and field widths (#11).
- Target: actions on the right, groups stacked (#12); saved targets as a list (#13); Ctrl+F (#14).

> Test version — back up your game saves.
