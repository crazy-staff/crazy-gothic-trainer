## Installation
1. Download **G1CrazyTrainer_build9.zip** (below, in *Assets*) and unpack it.
2. Copy all files into `Gothic\system\Autorun` (replace the old ones).
3. Start the game with **Union + GD3D11**, load a save, press **Insert**.

> The in-game menu is in Polish for now — English is planned.

## What's new in build 9

**Mods**
- Portraits: each character in its own spot + waiting a few frames, option to make portraits of all characters in the game (#3); **Compendium** in Tools (#4).

**Interface**
- Teleport: place type icons and chips (#10), even paddings and field widths (#11).
- Target: actions on the right, groups stacked (#12); saved targets as a list (#13); Ctrl+F (#14).
