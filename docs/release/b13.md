## Installation
1. Download **G1CrazyTrainer_build13.zip** (below, in *Assets*) and unpack it.
2. Copy all files into `Gothic\system\Autorun` (replace the old ones).
3. Start the game with **Union + GD3D11**, load a save, press **Insert**.

> The in-game menu is in Polish for now — English is planned.

## Build 13
- **Glide** is a separate option (mutually exclusive with no-clip) with a max slope slider 0–90°; walks on bridges and grates; leaving no-clip/glide puts your feet on the ground.
- **Party:** "Wait" holds the spot (returns to the point, not frozen); the party is not touched during conversations (dialogue lock); monsters run when far away; option "Stop fighting after teleport".
- **Target:** after adding to the party the button changes to "Remove from party"; new icon (person with a plus).
- **Arena:** loss counted from the real HP after a hit; no immortal enemies; names "Arena: Zombie" (ID in tester mode); starting wave + number of waves.
- **ESP:** character type marker ([Arena], [Party], [Spawned]).
- **Character:** name and portrait refresh in Information; guild in Information; look preview on a clone (auto or button) + "Apply look".
- **UI:** textarea handle in the bottom-right corner; info window in one card with checkboxes; more space above the slider in rows with a button.
- **Tools › Diagnostics › Rescue:** close a stuck conversation, unlock the hero, unlock the target.

> Test version — back up your game saves.
