## Installation
1. Download the **.zip** (below, in *Assets*) and unpack it.
2. Copy all files into `Gothic\system\Autorun` (create the folder if it does not exist).
3. Start the game with **Union + GD3D11**, load a save, press **Insert**.

Details: [README](https://github.com/dawidseipold/gothic1-crazy-trainer#installation) · Testing: [TESTING.md](https://github.com/dawidseipold/gothic1-crazy-trainer/blob/main/TESTING.md)
