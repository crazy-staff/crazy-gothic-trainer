## Installation
1. Download **G1CrazyTrainer_build11.zip** (below, in *Assets*) and unpack it.
2. Copy all files into `Gothic\system\Autorun` (replace the old ones).
3. Start the game with **Union + GD3D11**, load a save, press **Insert**.

> The in-game menu is in Polish for now — English is planned.

## Build 11 — fixes instead of new features
- **Spawning characters:** characters are inserted with the game function `oCNpc::Enable` (like the console `insert`) instead of the spawn manager, which left them without a body (#17).
- **Party and teleport:** the game no longer disables party members, spawned characters or your own body when swapping; disabled characters return to the world with their model (#35, #22).
- **Portraits:** no more generating from clones — the portrait is made live from the real character when you aim at it or save it. Leftover "TESTMODELL" clones are removed automatically (#3).
- **Look:** the "Apply look" button is always visible, no preview clone (#32).
- **No-clip:** camera set every frame, mouse read from the game state (works with ZMouseFix) (#20).
- Item price shown as "X ore"; option statuses updated from reports.
