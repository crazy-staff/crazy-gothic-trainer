## Class kits

| Kit | What you get |
|---|---|
| **Warrior** | the strongest one- and two-handed weapon, the best armour, 10 healing potions |
| **Archer** | the best bow and crossbow + 300 arrows and bolts |
| **Mage** | all runes, 20 mana potions, the best mage robe |
| **Thief** | all keys + 30 lockpicks |

## Everything of a kind

| Button | What you get |
|---|---|
| **All runes** | every rune |
| **All scrolls** | every scroll (amount of each is set next to it) |
| **All potions** | every potion (amount of each) |
| **All keys** | every key in the game |
| **All amulets and rings** | every amulet and ring |
