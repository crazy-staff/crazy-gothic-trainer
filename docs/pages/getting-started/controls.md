---
title: Controls
description: Keys of the trainer.
---

| Key | Action |
|---|---|
| **Insert** | open / close the menu (the game is paused meanwhile) |
| **Esc** | close the menu, leave no-clip / glide, stop portrait generation |
| **F11** | screenshot (with the menu) — copied to the clipboard and saved to `G1CrazyTrainer_zrzuty` |
| **Shift + F11** | screenshot of a selected area |
| custom hotkeys | any option: click the hotkey field next to it and press a key or combination |

> **Note:** The in-game menu is in Polish for now. An English interface is planned — vote for it on the [Feedback](/) board.
