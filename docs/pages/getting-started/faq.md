### The menu does not open

Check that **GD3D11** is installed and active (the menu is drawn by its DirectX 11 renderer) and that **Union** loads the DLL from `system\Autorun`. Press **Insert** in the game, not in Gothic's main menu.

### Does it work with other versions of Gothic?

Only the Steam version with `GothicMod.exe` 1.08k_mod for now.

### Is the trainer in English?

The docs are. The in-game menu is in Polish for now — an English interface is planned.

### Can I use it in multiplayer?

No — single-player only.

### The game crashed

Start the game again — the trainer detects the crash and prepares a draft report in the Tester hub. See [Testing and reporting](doc:testing).

### Something got stuck (dialogue, hero, NPC)

Use the rescue buttons in [Diagnostics](doc:diagnostics).
