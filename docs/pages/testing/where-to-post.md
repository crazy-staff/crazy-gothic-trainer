**Everything is in English** — ideas, comments and questions — so everyone can follow and help.

| You have… | Where |
|---|---|
| A new feature idea | [Feedback](/) — one idea per post. Search first and vote if it already exists. |
| A question | [Support](/support), or search these docs first. |
| A bug or a crash | the in-game **Tester hub** (best — it attaches everything) or [GitHub Issues](https://github.com/dawidseipold/gothic1-crazy-trainer/issues/new/choose) |

## What happens with an idea

1. **Pending** — new ideas wait for review. Votes help decide.
2. **Approved / Planned** — the idea appears on the [Roadmap](/roadmap) and gets a GitHub issue for the work.
3. **In progress → Needs verification** — it is in a test build and testers confirm it.
4. **Done** — shipped and listed in the [Changelog](/changelog). Voters are notified at every step. Ideas that will not be done are **Rejected** with a reason.

> **Tip:** Ports of open-source Union plugins and mods are welcome **with credit** — link the source in your idea.
