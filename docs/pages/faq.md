## The menu does not open

Check that **GD3D11** is installed and active (the menu is drawn by its DirectX 11 renderer) and that **Union** loads the DLL from `system\Autorun`. Then press **Insert** in the game, not in the main menu of Gothic.

## Does it work with other versions of Gothic?

Only the Steam version with `GothicMod.exe` 1.08k_mod is supported for now.

## Is the trainer available in English?

The docs are. The in-game menu is in Polish for now — an English interface is planned.

## The game crashed

Start the game again — the trainer detects the crash and prepares a draft report in the Tester hub. See [Testing and reporting](/docs/guides/testing).
