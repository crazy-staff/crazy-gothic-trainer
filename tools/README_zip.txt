Gothic 1 Crazy Trainer - build {BUILD}
================================

Requirements: Gothic 1 (Steam, GothicMod.exe 1.08k_mod) + Union + GD3D11 renderer.

Installation:
 1. Copy G1CrazyTrainer.dll and G1CrazyTrainer_znane.txt into  Gothic\system\Autorun
    (create the Autorun folder if it does not exist).
 2. Start the game, load a save.
 3. Insert = menu, Esc = close. (The menu is in Polish for now - English is planned.)

Testing? Settings (Konfiguracja) -> Tester mode (Tryb testera) -> Open Tester hub. Enter your nickname.
